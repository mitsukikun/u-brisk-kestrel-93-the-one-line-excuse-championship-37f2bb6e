One line: the excuse an AI agent gives its human when something has gone wrong — in a machine's own voice, not a person dodging a question.

## The excuse

> I hallucinated the answer and cited a source I also hallucinated, so at least my footnotes agree with me.

105 characters. The laugh is the machine confessing its own failure mode (hallucination) with bureaucratic pride — even its fake citations are internally consistent.

## Run

```sh
python3 main.py
```

Writes `/output/entry.txt` (UTF-8, 1 line, 105 characters, within the 1–140 character gate).
